# Visuals

This folder is intended for static chart exports (PNG/SVG). The interactive visualizations for this project are hosted on Tableau Public.

## Interactive Dashboard

**[View the Discipline Disparities Dashboard on Tableau Public](https://public.tableau.com/app/profile/yauncee.dorty/viz/CRDCDisciplineDisparities-StudentswithDisabilities/DisciplineDisparitiesDashboard)**

The workbook contains three views:

- **By Geography & Measure** — Discipline rates by measure type, disability status, and geography (National, Texas, and 4 ISDs)
- **National Disparity Overview** — Side-by-side comparison of students with vs. without disabilities across all measures and geographies
- **By Race & Disability** — OOS suspension rates broken down by race and disability status

All charts use blue (Students with Disabilities) / orange (Students without Disabilities) color coding for easy comparison.
